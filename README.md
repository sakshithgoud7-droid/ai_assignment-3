# AI Assignment

## Problem 1: Dijkstra’s Algorithm
Implemented Uniform Cost Search using Dijkstra’s Algorithm to find shortest paths between cities based on road distances.

## Problem 2: UGV Navigation with Static Obstacles
Designed a grid-based path planning system using A* algorithm to find the shortest path while avoiding obstacles. Different obstacle densities (low, medium, high) are considered.

## Problem 3: UGV Navigation with Dynamic Obstacles
Extended the solution to handle dynamic obstacles using repeated A* approach. The path is replanned whenever new obstacles appear in the environment.
